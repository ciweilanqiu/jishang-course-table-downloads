# 吉商课程表下载入口

本仓库仅用于公开下载页和版本清单，不存放应用源码、个人课表、认证信息或签名密钥。APK 将在完成签名与验收后作为版本化 GitHub Release 资产发布。

目前尚未发布 APK，`update.json` 故意不存在；下载页会明确显示“下载暂未开放”。不要将未验收的调试包称为正式版。

发布时先上传并验证 APK 的包名、版本、签名、下载及 SHA-256，再添加与资产匹配的 `update.json`。清单中的 `downloadUrl` 必须指向本仓库明确版本的 Release APK。固定页面地址由 GitHub Pages 设置确定；页面尝试自动跳转，也保留手动下载按钮。
